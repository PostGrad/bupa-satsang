Command Compass

Start API

pnpm start:api -> nx run api:serve -> pnpm exec tsx src/main.ts in apps/api.

Start Client

pnpm start:client -> nx run client:start -> pnpm exec expo start in apps/client.

Check All Types

pnpm typecheck -> nx run-many -t typecheck --all.

Lint All Projects

pnpm lint -> nx run-many -t lint --all.

Diagnostic Rule

Ask one question first: am I changing membership, task behavior, dependency visibility, or source code? Membership lives in pnpm-workspace.yaml. Task behavior lives in nx.json or project.json. Dependency visibility lives in each package's package.json. Source code lives under that app or package's src, app, test, or e2e folder.
