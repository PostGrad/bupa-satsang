Lesson 0001

How This Monorepo Is Set

Your win: after this lesson, you should be able to answer "which file owns this?" for most changes in the repo.

The Core Idea

This repo uses two layers together: pnpm decides which folders are workspace packages, and Nx decides which projects have runnable tasks. The root package.json is the front desk: it exposes friendly scripts such as start:api, start:client, typecheck, and lint.

Primary sources: pnpm Workspace docs, Nx Project Configuration, and Nx nx.json reference.

The Three-Layer Map

Layer 1Package membership
pnpm-workspace.yaml
Includes apps/* and packages/*.
Layer 2Task orchestration
nx.json and project.json
Nx runs named targets and caches selected tasks.
Layer 3Runtime/package behavior
Each app/package package.json
Declares dependencies, exports, package names, and entry points.

What Exists Here

apps/api

Nest application. Its Nx project is named api. Its serve target runs pnpm exec tsx src/main.ts from inside apps/api.

apps/client

Expo application. Its Nx project is named client. It has targets for start, web-build, android-build, android-run, typecheck, and lint.

packages/ui

Shared UI-adjacent package. It exports ./i18n, and the client imports @bupa-satsang/ui/i18n.

packages/test-support

Shared testing package. It exports ./fixtures and has its own Nx typecheck and lint targets.

The Most Important Dependency Link

The client depends on the UI package like this:

"@bupa-satsang/ui": "workspace:*"

In pnpm, the workspace: protocol means "resolve this dependency from this local workspace." That is why the client can import @bupa-satsang/ui/i18n without publishing @bupa-satsang/ui to a registry.

How To Locate Ownership

Use this checklist: If you add a folder to the repo, check pnpm-workspace.yaml. If you add or change a runnable command, check the relevant project.json. If one package needs to import another, check both packages' package.json. If behavior changed inside an app, start in that app's source root.

For exploration, nx show projects lists projects. In this repo it returned test-support, @bupa-satsang/ui, client, and api. In the Codex sandbox it also reported a Unix socket permission warning, but still printed the project list.
