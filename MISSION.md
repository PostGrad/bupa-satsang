# Mission: Understand The BUPA-Satsang Monorepo

## Why
The immediate goal is to confidently navigate, explain, and modify this repository without guessing which tool owns which part of the setup. The practical outcome is faster, safer project work across the Expo client, Nest API, and shared packages.

## Success looks like
- Identify whether a change belongs in root config, an app, or a shared package.
- Explain how pnpm workspace membership, Nx project tasks, and package exports fit together.
- Choose the right command to run after changing client, API, package, test, lint, or typecheck code.

## Constraints
- Lessons should stay short and grounded in this repository's actual files.
- Prefer local repo evidence first, then official docs for tool concepts.
- This mission is inferred from the first lesson request and should be refined when the user's deeper goal is clear.

## Out of scope
- Advanced release/versioning strategy for publishable packages.
- Large-scale monorepo migration patterns outside this repository.
